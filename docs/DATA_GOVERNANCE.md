# 数据治理与本地存储规范

## 数据来源与角色

| 数据 | 角色 | 获取方式 | 许可/限制 |
|---|---|---|---|
| IBM AML HI-Small | 主实验 | IBM AML-Data 链接的 Kaggle 数据页 | 数据为合成；遵守 CDLA-Sharing-1.0 与 Kaggle 条款 |
| Elliptic++ | 外部验证 | 官方仓库所列 Google Drive | 链上金融场景，不等同于传统银行交易 |
| AMLSim | 开发和压力测试 | IBM/AMLSim | 仅作受控模拟，不支撑主要实证结论 |

## 禁止提交的内容

GitHub 只保存代码、配置、下载说明、字段契约、审计 JSON 的结构示例和结果摘要。严禁提交：

- 原始交易 CSV、压缩包、图缓存、模型权重；
- 逐笔交易、账户标识、逐笔预测概率；
- 超过 50 MB 的派生文件。

GitHub 不应用作大数据存储。大文件既受单文件限制，也会永久增加仓库历史体积；完成实验后可删除 D 盘缓存，通过下载脚本和数据指纹重建。

## 本地目录

```text
D:\THG-OAFN-Financial-Experiment\
├── data_cache\     原始/派生大数据，可随时删除并重建
├── metadata\       数据审计、哈希、切分清单
└── runs\           预测、日志、检查点与图表
```

该目录不纳入 Git。每个运行必须写入 `metadata/`：原始文件大小、修改时间、可选 SHA-256、审计结果、Git commit、随机种子和配置副本。

## 时间因果约束

对时间为 `t` 的目标交易：

- 账户统计、邻居、图边和归一化参数只能取自 `time <= t` 的历史；
- 训练、验证和测试按时间切分，同一时间戳不得跨集合；
- 标签权重、阈值和校准器只用训练/验证数据；
- 任何使用未来窗口或全量统计量的特征必须被测试拒绝。
